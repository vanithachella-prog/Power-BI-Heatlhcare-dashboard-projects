# 🤖 Healthcare AI/ML Project – Smoking Data Quality Improvement

## 🔹 Overview
Explored AI/ML approaches to improve data quality in healthcare reporting, focusing on smoking status inconsistencies.

The goal was to identify incorrect classifications and enhance reporting accuracy.

---

## 🔹 Business Problem

- Patients incorrectly classified (e.g., Ex-smoker marked as Never Smoked)
- No validation before data reaches reporting layer
- Impacts clinical insights and decision-making

---

## 🔹 Solution Approach

Designed a conceptual ML-based validation pipeline:

1. Rule-based logic (existing business rules)
2. NLP-based extraction (patient history & codes)
3. Machine Learning model to detect inconsistencies

---

## 🔹 Key Components

- Data validation logic
- NLP exploration for healthcare data
- ML-based anomaly detection
- Automated flagging of incorrect records

---

## 🔹 Tools & Technologies

- Python (exploration stage)
- Azure Machine Learning (conceptual)
- SQL (data extraction)
- Microsoft ecosystem

---

## 🔹 Example Use Case

- Identify patients marked as “Never Smoked” but with historical smoking records
- Flag discrepancies before reporting layer

---

## 🔹 Key Learnings

- Importance of data validation in healthcare
- ML can enhance data governance processes
- Integration challenges between systems

---

## 🔹 Future Enhancements

- Full ML model deployment
- Integration with data pipelines
- Real-time validation layer
- Copilot-based insights for clinicians
